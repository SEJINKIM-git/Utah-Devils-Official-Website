# 운영진 관리자 계정 생성 가이드

관리자 페이지는 사이트 상단의 **ADMIN SIGN UP** 메뉴에서 회원 등록을 시작합니다. 등록된 계정은 사이트 상단 메뉴 또는 `/admin/login`에서 로그인할 수 있습니다.

## 계정 생성 순서

1. 사이트 상단의 **ADMIN SIGN UP**을 엽니다.
2. 회원 이름에는 해당 운영진의 **영문 이름**을 입력합니다.
3. ID에는 각자의 **UNID**를 입력합니다.
4. 로그인용 학교 이메일을 입력합니다.
5. 생년월일과 등번호를 입력하면 초기 비밀번호가 `생년월일(YYYYMMDD) + 두 자리 등번호`로 자동 설정됩니다.

예시: 생년월일이 2002년 3월 15일이고 등번호가 35번이면 초기 비밀번호는 `2002031535`입니다. 등번호가 한 자리면 앞에 0을 붙입니다. (2번 → `02`)

> UNID는 회원 식별 정보로 저장되며, 로그인 화면은 Supabase 이메일 인증을 사용하므로 생성 시 등록한 **학교 이메일 전체**를 입력해야 합니다.

계정을 전달한 뒤에는 보안을 위해 운영진이 첫 로그인 후 개인 비밀번호로 변경하도록 안내합니다. 초기 비밀번호와 개인정보는 공개 문서나 단체 채팅방에 남기지 않습니다.

## 운영진 승인

가입한 회원은 기본적으로 로그인만 가능한 `member` 권한을 받습니다. 사진 업로드, 연혁·행사 수정, 사이트 문구·설정 변경은 승인된 `admin` 권한이 있어야 가능합니다.

1. 회원이 가입을 완료합니다.
2. Supabase SQL Editor에서 `sql/08_member_registration_roles.sql`을 실행합니다. (최초 1회)
3. 같은 SQL 파일 마지막의 다음 구문에서 UNID만 실제 값으로 바꿔 실행합니다.

```sql
update public.admin_members
set role = 'admin', approved_at = now()
where unid = '실제_UNID';
```

4. 승인된 회원이 다시 로그인하면 `/admin` 관리 메뉴와 사이트 편집 모드를 사용할 수 있습니다.
