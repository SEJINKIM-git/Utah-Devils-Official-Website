# 운영진 관리자 계정 생성 가이드

관리자 페이지는 사이트 상단의 **ADMIN LOGIN** 메뉴에서 접근합니다. 계정 생성은 운영진 중 Supabase 대시보드 접근 권한이 있는 사람이 수행합니다.

## 계정 생성 순서

1. Supabase Dashboard에서 **Authentication → Users → Add user**를 엽니다.
2. 이메일(ID)에는 각 운영진의 **UNID가 포함된 학교 이메일 전체**를 입력합니다.
3. User metadata의 `display_name`에는 해당 운영진의 **영문 이름**을 입력합니다.
4. 초기 비밀번호는 `생년월일(YYYYMMDD) + 두 자리 등번호`로 설정합니다.

예시: 생년월일이 2002년 3월 15일이고 등번호가 35번이면 초기 비밀번호는 `2002031535`입니다. 등번호가 한 자리면 앞에 0을 붙입니다. (2번 → `02`)

> 로그인 화면은 Supabase 이메일 인증을 사용하므로 UNID만 입력하지 않고, 생성 시 등록한 **학교 이메일 전체**를 입력해야 합니다.

계정을 전달한 뒤에는 보안을 위해 운영진이 첫 로그인 후 개인 비밀번호로 변경하도록 안내합니다. 초기 비밀번호와 개인정보는 공개 문서나 단체 채팅방에 남기지 않습니다.
