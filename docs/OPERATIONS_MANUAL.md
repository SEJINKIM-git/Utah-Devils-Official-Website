# 운영 매뉴얼

## 운영진 계정 관리

운영진 계정은 사이트에서 가입시키지 않습니다. 시즌 시작·인수인계 시 Supabase 대시보드에서 이메일과 비밀번호로 직접 만듭니다.

### 1. 계정 만들기

1. Supabase 프로젝트 대시보드에서 **Authentication → Users**를 엽니다.
2. **Add user → Create new user**를 누릅니다.
3. 운영진의 학교 이메일과 임시 비밀번호를 입력합니다.
4. **Auto Confirm User**를 체크하고 생성합니다.
5. **Table Editor → admin_members**에서 방금 생성된 계정을 찾아 `role`을 `admin`으로, `approved_at`을 현재 시각으로 설정합니다. 이 단계가 있어야 기존 RLS 정책에 따라 콘텐츠·사진·설정 수정이 허용됩니다.
6. 당사자에게 이메일과 임시 비밀번호를 개별적으로 전달하고, 첫 로그인 뒤 `/admin/settings`에서 비밀번호를 변경하도록 안내합니다.

### 2. 비밀번호 재설정

1. Supabase 대시보드에서 **Authentication → Users**를 엽니다.
2. 해당 사용자를 열고 새 비밀번호를 지정합니다.
3. 새 비밀번호를 당사자에게 개별적으로 전달합니다. 이메일 발송은 필요하지 않습니다.

### 3. 계정 회수

운영진이 퇴임하면 **Authentication → Users**에서 해당 계정을 삭제하거나 비밀번호를 변경합니다. 계정을 삭제하면 `admin_members`의 연결 행도 자동으로 정리됩니다.

### 4. /admin에서 비밀번호 변경

1. `/admin/login`에서 로그인합니다.
2. 상단 **설정** 메뉴를 엽니다.
3. 새 비밀번호를 두 번 입력하고 **비밀번호 변경**을 누릅니다.

이 기능은 로그인한 본인 계정에만 적용되며, 이메일 발송을 사용하지 않습니다.
