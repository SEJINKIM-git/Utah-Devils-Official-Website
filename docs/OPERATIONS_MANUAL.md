# 운영 매뉴얼

기본 동선은 항상 **고칠 화면으로 이동 → `/admin` 로그인 → 사이트 편집 모드 열기 → 바꿀 내용을 클릭 → 저장**입니다. 저장하면 즉시 공개 화면에 반영됩니다.

## 1. 행사 올리기·고치기

1. `/admin`에서 **행사 관리**를 엽니다.
2. 새 행사라면 행사명·카테고리·날짜·설명을 입력하고 **행사 추가**를 누릅니다.
3. 목록에서 **수정**을 눌러 행사 사진 영역의 **행사 사진** 업로더로 사진을 추가합니다.
4. 공개 `/archive?tab=events`에서 제목이나 설명을 바로 고치려면 **사이트 편집 모드 열기** 후 해당 문구의 연필 아이콘을 누릅니다.
5. 삭제는 `/admin/events` 목록의 **삭제**를 누르고 확인합니다. 삭제한 행사는 되돌릴 수 없습니다.

[스크린샷: 행사 관리 화면]

## 2. 선수 사진 바꾸기

1. `/admin`에서 **사이트 편집 모드 열기**를 누릅니다.
2. `/players`에서 시즌과 선수 카드를 찾습니다.
3. 사진 위 **사진 교체**를 눌러 JPEG·PNG·WEBP 사진을 선택하고 **업로드**합니다. 아이폰 HEIC 사진은 먼저 JPEG로 변환합니다.
4. 저장 완료 뒤 `/players`와 메인 화면에서 변경된 사진을 확인합니다.

[스크린샷: 선수 사진 교체]

## 3. 경기 결과가 안 보일 때

1. `/admin`에서 **경기 상태**를 엽니다.
2. 현재 시즌의 최근 10경기와 `시간 누락`, `상대 팀 표기 확인`, `과거 경기 스코어 누락` 안내를 확인합니다.
3. 입력·수정이 필요하면 **Devils Insight AI 열기**를 누릅니다. 홈페이지에서는 경기 기록을 수정하지 않습니다.
4. 분석 플랫폼 저장 후 홈페이지를 새로고침해 확인합니다.

[스크린샷: 경기 상태 보드]

## 4. 공지와 기본 시즌 설정

1. `/admin`의 **설정**을 엽니다.
2. **사이트 운영 설정**에서 공지 배너, 현재 시즌, 목표 경기 수, SNS 링크를 수정합니다.
3. **사이트 설정 저장**을 누릅니다. 공지 배너는 비우고 저장하면 사라집니다.

[스크린샷: 사이트 운영 설정]

## 5. 수요조사와 계정

1. 수요조사는 `/admin/survey`에서 상품 연결·사이즈·안내문을 정하고, 마감 뒤 사이즈별 집계와 CSV를 확인합니다.
2. 운영진 추가·비밀번호 재설정·회수는 `/admin/members`에서 합니다. 임시 비밀번호는 당사자에게 개별 전달합니다.
3. 본인 계정과 마지막 남은 운영진 계정은 삭제할 수 없습니다.

## 6. 비상 대응

1. 배포 문제가 있으면 Vercel에서 직전 정상 배포를 **Promote**해 롤백합니다.
2. `/api/health`를 열어 사이트 상태를 확인합니다.
3. 해결이 안 되면 오류 화면 스크린샷과 이 문서를 Claude에 첨부해 질문합니다.
4. 모든 운영진이 로그인할 수 없는 경우에만 Supabase 대시보드에서 Auto Confirm으로 복구 계정을 만들고, `admin_members`에 `role=admin`, `approved_at=현재 시각`을 설정합니다. 복구 후에는 `/admin/members`로 돌아갑니다.

## 7. 키 관리

`SUPABASE_SERVICE_ROLE_KEY`는 서버의 운영진 계정 관리 API에서만 사용합니다. 유출이 의심되면 Supabase에서 키를 rotate하고 Vercel 값을 교체한 뒤 재배포합니다.
